# Iran Israel - Visual News Feed

## Project Overview
The "Iran Israel" application is a mobile platform designed to allow users to share and view the latest regional news exclusively through images and videos. It functions similarly to Twitter, with the key distinction being a 100% focus on visual content (photos and videos); simple text-only posts are not allowed. The primary goal is to provide a visual, engaging, and fast news feed of events in the specified region.

## MVP Features
*   User sign-up & login
*   Basic user profiles (username, profile photo)
*   Visual content posting (photos/videos with captions)
*   Main feed (reverse chronological, full-width visuals)
*   Basic interactions (like, comment, follow/unfollow)
*   User post reporting

## Technology Stack (Proposed)
